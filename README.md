# ibf_viz

Impact-Based Flood Forecast Viewer. Operational warning maps for the project pilots in
Guatemala (Rio Villalobos, probabilistic) and Barbados (island-wide scenario, deterministic).

Every building, road segment and district is colour coded green, yellow, amber or red by the
Flood Risk Matrix (likelihood x potential impact severity) of the Scottish Flood Forecasting
Service and the UK Flood Guidance Statement, following Speight et al. (2018), Journal of
Flood Risk Management 11, S884-S901.

## Repository layout

- index.html : landing page
- guatemala/index.html : interactive warning map, probabilistic mode
- barbados/index.html : interactive warning map, deterministic scenario mode
- methods/index.html : method and design note (v1)
- .nojekyll : tells GitHub Pages to serve files as they are

The map pages are fully self contained (Leaflet and all data are inlined), so the site has no
build step and no dependencies. Basemap tiles load from public tile servers when online; the
warning layers work offline too.

## How the maps are produced

The maps are generated by a configurable Python routine (ibf_routine.py, make_maps.py,
map_template.html) kept with the project files under IBF_design/final_product_v1. To publish
a new event or an updated version: run the routine, then copy the two generated HTML files
into guatemala/index.html and barbados/index.html and push.

## Enabling GitHub Pages (first time only)

1. Push this repository to GitHub (main branch).
2. On GitHub open Settings, then Pages.
3. Under Build and deployment choose Source: Deploy from a branch.
4. Select branch main and folder / (root), then Save.
5. Wait one or two minutes; the site appears at https://ahwalab.github.io/ibf_viz/
